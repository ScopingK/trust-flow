# TRUSTFLOW — Adaptive Fraud-Protection Layer

> **Tagline:** Verify before you trust.

TrustFlow evaluates transaction context, detects social engineering signals, calculates dynamic risk scores, and applies adaptive friction—activating a trusted family shield when critical threats occur.

## Core Hero Scenario
1. **Threat Detected:** Intercepts suspicious SMS/call claiming account block.
2. **Transaction Check:** Evaluates ₹80,000 transfer to a new beneficiary at 2:13 AM from an unusual location.
3. **Risk Scoring:** Calculates a **91/100 Critical Risk Score**.
4. **Family Shield:** Simulates real-time notification dispatch to a designated trusted contact.
5. **Protection:** Prevented scam transfer after family verification.

## Features Included
* **Beneficiary Verification:** IFSC, account format, and name-matching validation.
* **Social Engineering Engine:** Keyword and pattern-based SMS analysis.
* **Claim Verifier:** Guidance against caller-ID spoofing.
* **Multilingual Safety Assistant:** Support for English, Tamil, and Hindi.
* **Hero Demo Mode:** 60-second end-to-end interactive simulation.

## How to Run Locally
No build setup or dependencies required. Simply clone the repository and open `index.html` in any web browser.
